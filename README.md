Web Refresher: Artisan Margherita Pizza Page

Reflection

Building this single-page recipe website was a valuable exercise to refresh my front-end fundamentals before starting Web Development II. 

Structuring the semantic HTML with header, nav, main and footer elements was straightforward and intuitive. The organizing of the initial text and establishing the page hierarchy came together quickly as well. 

The most challenging part of the project was managing responsive layout behavior using CSS Grid and Flexbox. I had to make sure that the multi-column desktop layout stacked cleanly on mobile screens and also keep the sticky sidebar aligned. This needed careful debugging in the browser developer tools. The management of dynamic quantity calculations in JavaScript also required close attention to avoid DOM update bugs.

For Web Development II, I want to improve my JavaScript state management and DOM manipulation skills so I can build more scalable interactive components.
